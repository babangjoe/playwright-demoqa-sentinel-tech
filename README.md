# Playwright Automation - DemoQA - Sentinel Tech

## 🚀 Tech Stack
- Playwright
- JavaScript
- Page Object Model (POM)

## 📦 Installation
``` bash
npm install

npx playwright install chromium firefox
```

## ▶️ Run Test
``` bash
npx playwright test
```

## 📊 Generate Report
``` bash
npx playwright show-report
```
